实时股价（多股票版）· 浏览器扩展安装说明
==========================================

功能
----
- 在所有网页之上显示可拖动的全局悬浮球，实时显示最新价、涨跌幅（红涨绿跌）
- 支持自行配置多只股票（A股 / 港股 / 美股 / 场内ETF/LOF / 上金所现货黄金），悬浮球行情卡顶部标签栏一键切换
- 无任何预设股票：所有股票均由您自行搜索添加，完全自由配置
- 点击悬浮球展开行情卡：今开/昨收/最高/最低/成交量/成交额/换手率/振幅/市盈率/市净率/总市值/流通市值/涨停/跌停 + 实时迷你走势
- 行情卡顶部「AI 智能研判」实时汇总方向判断、上行概率、预测区间与量化评分；「智能预测」区含实时/次日双模式预测、主力资金流与龙虎榜、热榜资讯、量化综合评分，仅作技术参考
- 盘中每 3 秒自动刷新，收盘后每 15 秒；按市场自动识别交易时段
- 拖动悬浮球移动位置，松手自动贴边停靠，位置跨网页记忆；首次使用有操作提示
- 配置修改后所有已打开网页实时同步生效
- 数据源：腾讯行情（主），A股失败自动降级东方财富（备用）；样式 Shadow DOM 完全隔离

如何添加股票
------------
方式一（最快）：点击浏览器工具栏的扩展图标，弹出配置面板
            - 在搜索框输入名称/代码（如：茅台、002895、hk00700、usAAPL、510300）
            - 点击候选项即加入列表并设为当前展示
            - 已配置列表中点击某项即可切换展示，悬停该项可移除
方式二：点击悬浮球展开行情卡 → 「设置」按钮 → 完整设置页添加/切换/移除
方式三：在扩展管理页（chrome://extensions）点击本扩展「详情」→「扩展程序选项」

预测参考说明
------------
- 次日预测基于近 120 个交易日日K线统计：均线 MA5/10/20/60、MACD、RSI、KDJ、BOLL、ATR、OBV、ADX、CCI 等多指标合成方向与概率，经滚动回测校准给出次日区间
- 实时研判基于分时K线（VWAP 位置、30分钟动量、量比、日内位置）与大盘联动给出盘中方向与区间；量化评分由趋势/资金/量价/情绪/估值五因子加权合成（权重可在设置页调整）
- 该预测为简易技术性参考，不构成任何投资建议，市场有风险
- 港美股只展示核心行情与市盈率，预测仍可用（基于其日K线统计）
- 交易时段判定：A股/港股/上金所按北京时间，美股按纽约时区自动适配夏令时

安装（Chrome / Edge）
---------------------
1. 打开浏览器，地址栏输入并回车：
     Chrome：chrome://extensions
     Edge：edge://extensions
2. 打开右上角「开发者模式」开关
3. 点击「加载已解压的扩展程序」，选择本文件夹（含 manifest.json 的那一层）
4. 加载成功后，打开任意网页即可看到悬浮球

升级说明
--------
- 若已安装旧版（2.x 及更早），请先在扩展管理页「移除」，再重新加载本文件夹
- 旧版单股票配置会自动迁移为列表中的第一只股票；新版完全无预设股票
- 配置保存在浏览器扩展存储中，卸载扩展后配置会清除

注意事项
--------
- 需要 Chrome 109+ / Edge 111+（支持 Manifest V3）
- 浏览器内置页面（chrome://、应用商店、PDF 查看器等）出于安全限制不显示悬浮球
- 行情来自公开免费接口，仅供展示；接口偶有波动，扩展已做双源切换与重试
